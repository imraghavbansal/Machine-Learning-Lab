# Machine-Learning-Lab

A hands-on collection of machine learning projects, implementations, and experiments built while learning and strengthening ML fundamentals.

## Focus

- Machine learning fundamentals
- Data preprocessing and analysis
- Model training and evaluation
- Classical ML algorithms
- Experimentation and model comparison
- Gradually progressing toward deep learning and modern AI

## Structure

Each project lives in its own directory with its own README containing the implementation details, experiments, results, and learnings.
